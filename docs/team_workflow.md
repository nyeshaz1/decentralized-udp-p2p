# Git Workflow
- NEVER commit to main. main = stable demo-ready code, leader only.
- develop = integration branch. Everyone opens Pull Requests into develop.
- Branches: feat/leader-transport, feat/areesha-membership-chat, feat/hamza-storage-transfer
- Commit small and often: "area: what changed". Pull develop daily: git pull origin develop --rebase
- Do not edit another member's folder or common/interfaces.py or docs/protocol.md without asking the leader.
